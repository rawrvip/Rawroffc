Kirim pesan WhatsApp

Gunakan WhatsApp Cloud API resmi. Masukkan API key dari pemilik server, nomor tujuan format internasional (contoh 6281234567890), lalu pesan.

API key hanya digunakan untuk permintaan ini dan tidak disimpan di browser. Jangan bagikan API key server kepada orang yang tidak dipercaya. Pengiriman tetap memerlukan akun WhatsApp Business dan kredensial Meta yang disiapkan pemilik server.
